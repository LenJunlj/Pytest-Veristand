# samples/ —— TestStand 存量序列解剖区（P2 输入）

从台架机拷 2~3 个代表性 `.seq` 到本目录：

| 类型 | 要找什么样的 | 数量 |
|---|---|---|
| 纯稳态 | 设工况 → 等稳定 → 读值 → 判定，机制最简单 | 1 |
| 故障注入 | 注入故障 → 验证保护/诊断反应 → 清除 | 1 |
| 机制最复杂 | 局部变量/表达式/序列调用/流程控制用得最多的那个 | 1 |

注意：
- 保留原始文件名即可，不用改名；
- `.seq` 是 XML 明文，拷贝不需要在开发机装 TestStand；
- 若同一序列还引用了别的文件（.seq 依赖、参数文件），一并拷来；
- 拷完在下面补一行登记（来源/用途），后续解析脚本按本目录扫描。

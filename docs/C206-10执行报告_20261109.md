## 3. 失败逐条分析

### 3.1 原文期望值缺陷（建议改期望，非 DUT 问题）

**① 左后 12 / 右后 11 —— 本地前提条件测试_Pre_Off**
- 现象：`硬线输出 0.0 != 期望 1`
- 实测：VDC_PowerMode=3（Pre_Off）时 DUT **立即停止加热**（<1s），恢复 4（Standby）后正常
- 原文自相矛盾：同一 power mode 下，`退出条件_Standby-Pre_Off` 期望停止（**该条通过**），
  而 `前提条件_Pre_Off` 期望继续加热。按 DUT 行为与原文自身另一条，**前提_Pre_Off 的期望写反了**
- 建议：该条期望改为全 0（hard=0 / can=0 / 灯全 0），或标 `xfail(strict)` 保留原样

**② 右后 12 —— 本地前提条件测试_Pre_On**
- 现象：`档位灯 R1=1`，期望 0
- 原文同一用例**第一组**灯期望全 0、**第二组**期望 R1=1，自身矛盾；实测两组都是 R1=1
- 建议：第一组灯期望改为 `(0,0,0,1,0,0)`（与第二组一致）

**③ 右后 19 —— 本地退出条件测试_OTA限制**
- 现象：`硬线输出 1.0 != 期望 0`（写 OTA 后的判定）
- 实测：OTA=1 后约 1s 内停止加热；但原文在写 OTA 后**不等待就采集**（左后同类用例有 wait 2）
- 原因：原文缺等待（存量缺陷）
- 建议：写 OTA 后补 `sleep(2)`（左后 20 已证明 2s 足够）

### 3.2 DUT 行为与原文期望不一致（需产品判断）

**④ 右后 09 —— 本地触发条件测试_加热上下电不记忆挡位**
- 现象：`硬线输出 1.0 != 期望 0`（上电后判定）
- 实测：PowerMode 4→0→4 后，右后加热**自动恢复**（记忆挡位），原文期望"不记忆"
- 需要确认：这是本版 DUT 的行为变更，还是原文期望已过时

**⑤ 左后 19 —— 本地退出条件测试_电压8.5V**
- 现象：`硬线输出 1.0 != 期望 0`
- 实测：8.5V 后 DUT 在 **约 11s** 才切断；原文在 **约 3s** 处采集（且结构上是"先采集后等待"，
  断言读的是 3s 的快照，永远看不到 11s 的切断）
- 同类先例：p2546 test_41（8V×6s 锁存）由用户改工况后通过
- 建议：按"实证改工况"处理——把采集点移到欠压后 12~15s，或标 `xfail(strict)` 并记录实测时延

### 3.3 DTC 恢复时延边界（不稳定项）

**⑥ DTC 01 过压 / 02 欠压**
- 现象：02 卡在"回 12V + 3s 仍报故障"；01 单独跑通过、全量跑失败 → 状态相关
- 实测时序（2026-11-09 探针）：
  - DTC 出现：施加 16.8V / 8.3V 后 **约 10s**（原文 6s 期望 False、11s 期望 True，正好卡上）
  - 回压恢复：过压 **<2s** 清零；欠压 **约 5s** 清零
- 原文欠压恢复只等 **3s**，落在 5s 的边界内侧 → 偶发失败
- 建议：欠压恢复等待 3s → 6s（过压保持 2s 不必改）；或标 `xfail(strict)` 观察
